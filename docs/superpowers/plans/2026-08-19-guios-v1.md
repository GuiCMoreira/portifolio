# GuiOS v1 — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir o portfólio GuiOS — um "sistema operacional" interativo dark (janelas, dock, terminal, ⌘K) com adaptação mobile para "smartphone OS", bilíngue PT/EN, pronto para deploy na Vercel.

**Architecture:** Aplicação Next.js de página única onde uma store Zustand gerencia janelas (window manager) e um registry de apps alimenta desktop, dock, mobile home e command palette. Conteúdo estático tipado em `src/data/`; i18n próprio via Context.

**Tech Stack:** Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 + shadcn/ui (cmdk) + Framer Motion (`motion`) + Zustand.

## Global Constraints

- Idiomas PT-BR e EN em TODO texto visível (dicionário próprio, sem lib de i18n).
- `prefers-reduced-motion` respeitado em toda animação (boot, janelas, zoom mobile).
- Breakpoint da metáfora: `< 768px` = smartphone OS; `>= 768px` = desktop OS. Sem user-agent sniffing.
- Componentes de terceiros (reactbits/cult-ui/skiper-ui) sempre copiados/adaptados em `src/components/ui/`, nunca dependência de runtime.
- Terminal nunca lança exceção por input do usuário.
- Portão por task: `npm run lint` + `npx tsc --noEmit` + `npm run build` verdes antes do commit.
- Commits no formato `PORTFOLIO | TIPO | DESCRICAO`, sem Co-Authored-By, na branch `feature/guios-v1`.
- Checar dependências novas no Sonatype Guide antes de instalar.

```ts
// src/lib/store.ts — Zustand
interface OSStore {
  windows: Record<AppId, WindowState>;
  focused: AppId | null;
  booted: boolean;
  openApp(id: AppId, payload?: string): void;   // abre/restaura + foca (z-index incremental)
  closeApp(id: AppId): void;
  minimizeApp(id: AppId): void;
  toggleMaximize(id: AppId): void;
  focusApp(id: AppId): void;
  setPos(id: AppId, pos: {x:number;y:number}): void;
  setBooted(b: boolean): void;
}
export const useOSStore = create<OSStore>(...);
```

```tsx
// src/lib/i18n.tsx
export function LanguageProvider({children}: {children: React.ReactNode}): JSX.Element;
```
